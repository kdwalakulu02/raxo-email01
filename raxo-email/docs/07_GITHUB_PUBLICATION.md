## Local quickstart contract to verify in G11

The final quickstart should be equivalent to:

```bash
npm ci
cp .env.example .env
mkdir -p config
cp config/forms.example.json config/forms.json
node --input-type=module -e 'import {randomBytes} from "node:crypto"; import {readFileSync,writeFileSync} from "node:fs"; const p=".env"; const s=readFileSync(p,"utf8"); if(!/^IP_HASH_SECRET=$/m.test(s)) throw new Error("Expected blank IP_HASH_SECRET"); writeFileSync(p,s.replace(/^IP_HASH_SECRET=$/m,"IP_HASH_SECRET="+randomBytes(32).toString("hex")));'
npm run services:up
npm run db:migrate
npm run demo:verify
```

The secret-generation command expects the newly copied blank example and refuses to replace an existing secret. Run this only in the fresh quickstart directory. If an additional setup step proves necessary, include it explicitly instead of hiding it.

For manual browsing, run npm run dev and npm run dev:worker in separate terminals and open http://127.0.0.1:3000/demo/job-application in local demo mode, plus Mailpit UI at http://127.0.0.1:8025.

Never make those localhost examples point to a live public endpoint.
